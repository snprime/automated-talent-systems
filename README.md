# Automated Talent Systems

A self-contained comparison page for job seekers, covering LinkedIn’s recruiting process and New York City’s applicant oversight. The page includes an accessible view toggle, qualitative process diagram, source notes, and original-source links. It uses embedded CSS and JavaScript with no external dependencies; only source links need an internet connection.

## Publish with GitHub Pages

1. Create a public GitHub repository, or open the repository you want to use.
2. Upload `index.html`, `.nojekyll`, and this `README.md` to the repository root and commit them to `main`.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. Wait for deployment to complete. GitHub will show the published site address on the Pages settings screen.

Keep `index.html` at the repository root so the site opens at its base URL.
